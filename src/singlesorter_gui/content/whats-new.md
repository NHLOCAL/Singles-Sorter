# מה חדש בגרסה 14.0.1

- ממשק חדש, נקי ומותאם לעברית ול־RTL.
- תמיכה מלאה ב־Windows וב־Android באמצעות Flet 0.85.3.
- מסך הגדרות מלא ונגלל עם פעולות שמירה וביטול קבועות.
- ברירת מחדל פשוטה: העברת הקבצים ללא תיקיית ״סינגלים״ פנימית.
- הפרדה מלאה בין CLI קל לבין חבילת הממשק הגרפי.
- עיבוד ברקע, הצגת התקדמות וביטול בטוח.
- החזרת מרכז העזרה, אודות, בדיקת עדכונים, רשימת זמרים אישית ותיקון שמות.

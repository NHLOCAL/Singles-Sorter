# Current-domain read-only restart backend

This backend-only composition follows the source-cleared controlled selected-job adapter `6db471a` and current-base Fix descriptor composition `5d07278`. Host/renderer activation is a separate gate.

## Admitted descriptors and fresh evidence

The historical single Copy/same-volume Move descriptor helpers are restored without replacing the current copied-Move parser, journal schema, route-specific metadata rules or native stream verifier. The data-only descriptor now also accepts exactly the current validated `SelectedWindowsCopiedMove` domain. It exposes job/path/identity/operation display evidence, never a writable binding or retained mutation session.

A copied-Move descriptor always remains inspection-needed. Even a strictly valid finished journal does not set its `recorded_complete` field. Fresh explicit source and target grants must reproduce the recorded lossless selected root paths and full identities. Strict current physical/cohort replay then runs with a live `InspectionControl`. Every matched created directory is held through the content checks; a missing/replaced directory remains separately unverified. The metadata prepass still checks all required copied destinations before any main/ADS reads. Reappeared sources, missing/foreign targets and changed streams cannot be adopted as a completed retired cohort.

The cursor only changes fresh observation order. Operation IDs and the final dependency pass remain in original order. Every source/destination, including repeated required-cohort reads and named streams, is read again. Historical hashes and earlier cancelled observations are never reused as current proof. Results describe observations across an inspection interval, not an atomic snapshot.

The existing conservative no-control Copy/rename diagnostic keeps its small recorded-input, observation and cumulative-byte ceilings. Its budget now explicitly refuses copied Move; copied-Move reconciliation requires the controlled API so ADS reads cannot evade a legacy aggregate budget. Controlled media verification has fixed-size buffers and no aggregate media-byte ceiling. Recorded-input ceilings remain explicit; exhausted or cancelled jobs stay unresolved. No journal is appended, truncated, rewritten, replayed or deleted.

Fix uses the separately reviewed data-only header/framing descriptor and freshly selected source-only repair-root reader. The observed root alias remains derived from the fresh held root and is never deserialized as authority. No Album family or absent-root grant is activated by this composition.

# Fixed-provider recovery admission policy (owned validation candidate)

`RetainedJournals` centralizes the startup reader's exact private byte, sequence and authority checks for later native recovery operations. It returns immutable serialized records with the SHA-256 of each original private file; accessors return fresh JSON objects. It preserves 1,000-directory, 64 MiB aggregate and per-file limits, no-follow regular reads, cancellation and explicit descriptor ownership. Callers must hold the appropriate diagnostic or execution ownership; the reader itself never changes data.

`RecoveryAdmission` is called before preview eligibility and again by the execution owner before journal creation. Its policy keeps unreadable/unknown journals fail-closed and checks both old source and target roots for each unresolved valid record. A new pair must be independently picker-authorized, currently present system ExternalStorageProvider directories and freshly disjoint in both `isChildDocument` directions, with equal document IDs always rejected. At most 64 distinct affected roots are queried. IDs remain provider-scoped references, not stable object identity or CAS. The original quiescent provider assumption remains mandatory.

The native `recovery_scope_admitted` flag is emitted only after this check and original-plan preparation succeed. It permits the shared UI to act on that fresh Android preview despite an attention notice, while retaining the historical notice. Unreadable history never permits the override. Settings/root changes invalidate the preview, and execution repeats admission without trusting the renderer flag. Actual owned-device disjoint-root acceptance is still pending. Work on an affected root still needs the planned retained-effects review/acknowledgment flow. No old journal is rewritten, no prior job becomes successful, and no intent is replayed.

Ancestry uses the fixed Android 11 provider call contract (`android:isChildDocument`, `uri`, `android.content.extra.TARGET_URI`, `result`) only for the verified local system authority. Unlike the public convenience wrapper, the result must be an explicit Boolean and provider exceptions propagate. Null, missing and wrong-type results fail closed. The same checked helper hardens the existing selected-root disjointness guard. Root parsing, deduplication and budget reservation precede any query for an affected root. The wire contract is pinned to [Android 11 platform source](https://github.com/aosp-mirror/platform_frameworks_base/blob/android-11.0.0_r1/core/java/android/provider/DocumentsContract.java); actual provider execution remains a device acceptance requirement.

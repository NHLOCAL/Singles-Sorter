# File-Album recorded descriptor admission

`inspect_recorded_album_file_job` is a data-only discovery helper for the file-Album manifest family. It returns recorded source/target observations, optional schema-2 native original-root observation, binding digest, counts and original album operation IDs. It returns no scope, writable binding, native grant, historical completion flag or current filesystem status. It performs no filesystem I/O. Host activation and fresh-root reconciliation remain a later slice.

A separate untrusted header DTO is deserialized. Neither `AlbumScope` nor the validated execution wrapper acquires `Deserialize`. The private planner snapshot stays serialization-only. Conversion is bounded and checks cancellation; snapshot admission independently reconstructs the collector's ordered membership expansion. It checks root separation, Windows references/identities, source-child parent relationships and exact non-root name/reference-leaf equality, directory membership, sanitized top-level album children, exact recursive destination mapping, original operation IDs, contiguous per-album file-index spans, postorder copied directories/cleanup, target directory requirements and existing target-parent identities. Every serialized projection must agree with that reconstruction. Bound physical operations must agree in order, source/digest, destination digest, mode, dependency chain and unique destination; source-cohort/resource/scope evidence must agree exactly. Copied-directory metadata cannot be followed by another original operation writing under it.

Schema 1 remains Copy/rename without an original native-root field. Schema 2 is copied Move with the exact native original root's full identity, parent identity and UTF-16 leaf/reference relation. Selected short aliases are not substituted for that native leaf. These are historical data checks; the separately reviewed parent inspector will still require a fresh exact containing-parent grant before any original-leaf absence can be used. Legacy missing native alias evidence is not repaired by inference.

The descriptor checks bounded input and record hash-chain framing, while preserving a trailing incomplete record for later inspection. It does not infer phase completion from framing. Strict phase replay is the existing shared `FileManifestEvidence` implementation, and final consistency will also require freshly granted roots, repeated original-leaf probes, held target directory identities, metadata-before-content/cohort verification, complete current main/ADS reads where a recorded baseline exists, and final pin revalidation. Identity-less candidates cannot count as acknowledged historical effects. A recorded header or cursor cannot substitute for those observations.

Current ceilings remain 4 MiB per record, 64 MiB per journal, 65,536 records, 4,096 physical/original operations, 8,192 snapshot directories and depth 128; the existing recorded membership ceiling is 100,000 entries and remains constrained by the smaller header-byte ceiling. These are practical limits, not unlimited-library acceptance. Media streaming is a separate inspection concern.

Eight authored Windows cases feed this decoder manifests produced by completed owned Copy and genuine two-volume copied-root jobs, and exercise mapping/membership/cleanup/parent forgery, native-root field forgery, truncated/corrupted framing, cancellation and limits. The second-volume target owner remains alive for the entire descriptor test. Existing strict phase replay tests remain unchanged; the Album gate rises from 38 to 46. Source/diff checks are the only local evidence. Native execution, compilation and formatting remain pending CI; this checkpoint does not activate Album restart in the desktop or CLI.

The name/reference check preserves the selected-root alias exception. Two forgery cases consistently rewrite every matching source observation, sanitized destination, destination digest and scope digest while keeping the actual source reference unchanged, covering both a direct album file and a standalone file in a mixed job. Both must be refused before a descriptor is returned.

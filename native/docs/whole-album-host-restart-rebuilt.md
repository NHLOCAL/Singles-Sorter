# Whole-Album fresh-host inspection

This is the reconstructed source candidate after workspace replacement, not the
lost unpublished host commit. It preserves the user's current template, studio
layout, and root `.gitignore` rule. The only newly authored Rust files explicitly
staged under that ignored source directory are `recovery_whole.rs` and
`recovery_whole_tests.rs`.

The host retains the strict data-only descriptor and exact journal identities,
lengths, timestamps and digests from discovery. A fresh existing source or an
explicitly selected original parent and fresh target are required. Journal bytes
never grant native lookup or mutation authority. The controlled native façade
reopens only its fixed retained journal names and revalidates every file.

`recorded_main_hash_identity_membership` is an explicit historical scope. Main
file hashes, identities and before/after directory membership are checked; old
Whole journals have no named-stream digest baseline. Both history and results
show that limitation. Atomic album descendant rows are file inspections, not
fabricated transfer receipts. Genuine deferred singles retain their own evidence.

All-clear requires the producer's exact lowercase `complete` Whole outcome,
matching recorded and mirrored child-rename acknowledgments, both exact current
child locations, every descriptor file and directory, fresh root evidence,
complete membership coverage, and all outer/nested terminal records. Nested File
manifests use their own uppercase `Complete` vocabulary. Missing, extra, duplicate
or contradictory receipt evidence cannot produce all-clear. No automatic replay,
cleanup, or writes are exposed by inspection.

The mandatory writer-fed native host fixture covers selected-root and mixed
album Move, two sanitized children, exact evidence projection, deterministic
media-byte cancellation and resume, Busy release, no writes, historical ADS scope,
changed main data and an added empty directory. Staged and extracted consumers
must each reopen root and mixed Whole jobs through real pickers and preserve the
entire owned trees and application journals during inspection.

Local evidence on this candidate: 180 renderer tests and typecheck, 135 Python
helpers (one Windows-only skip), 33 package-contract tests, 50 Linux host tests,
strict Linux host Clippy, and Windows selected-execution all-target cross-Clippy
for the host, executor and CLI.
The latter typechecks real Windows code but cannot execute native Windows APIs.
Native Windows host/backend execution and staged/extracted consumer acceptance
remain required. No original-model or runtime performance claim follows from
these local checks.

# Android interrupted-job startup

An unresolved or unreadable private journal is projected as a bounded recovery notice rather than a disconnected transport. Root selection, preview and explicit diagnostic export remain available. Native admission still performs the existing journal check, and the renderer does not offer apply while the notice is present.

This projection reports only historical `verified` acknowledgments from bound authority/state/index bytes. It does not revalidate current provider objects, attribute an unacknowledged move/deletion, resume a job, rewrite a journal, or release admission. The original journal remains immutable. Missing, malformed, over-budget or inaccessible private evidence is explicitly unreadable, with no invented counters.

The private scan uses the existing trusted-parent containment boundary, no-follow nonblocking regular file reads, bounded directory iteration (1,000), a 64 MiB aggregate byte budget, per-file limits, and the process diagnostic lease. Activity destruction cancels the scan without waiting on its I/O monitor. The fixed provider's quiescent execution assumption is unchanged. Resource-scoped reconciliation and any explicit release policy are separate work.

A historical `verified` acknowledgment still requires prior returned and observed publication (`publish-copy`, `publish-move`, or direct `move`). This is a historical producer-sequence check, not a fresh provider or cryptographic authenticity claim. Unknown subactions and incomplete publication sequences are unreadable.

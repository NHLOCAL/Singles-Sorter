# Read-only v2 examples

These JSON documents are templates, not runnable against a user's library.
Replace the illustrative absolute paths with disposable owned synthetic fixture
directories. Windows paths use JSON-escaped backslashes. Sort needs an existing
target; FixNames needs no target. Tests use copies of committed owned audio from
`../tests/fixtures/media`, whose README records provenance.

The Linux adapter is test-only. Native Windows runtime and Android validation
remain pending. Every response is non-executable; no physical transfer, rename
or tag save is exposed. See `../README.md` for the complete v2 request/response
contract, resource behavior, AI limitation, and immutable-manifest tests.

מסדר הסינגלים ל־Windows x64
===========================

התוכנה ממיינת קובצי מוזיקה לתיקיות לפי אמן ומתקנת שמות קבצים ותגיות.
שני מודלי הזיהוי פועלים במחשב עצמו, בלי שירות ברשת ובלי הורדה בזמן השימוש.

דרישות
------
Microsoft Edge WebView2 Runtime ו־Microsoft Visual C++ Redistributable x64.
ב־Windows 11 הרכיבים בדרך כלל כבר מותקנים. הורדה מאתר Microsoft:
https://developer.microsoft.com/microsoft-edge/webview2/
https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist

הפעלה
------
חלצו את כל ה־ZIP לתיקייה חדשה ופתחו את singles-sorter-desktop.exe.
אין להעתיק רק את קובץ ה־EXE: קובצי המודלים חייבים להישאר ב־models\original שלידו.

שימוש
-----
1. בחרו תיקיית מקור, ובמיון גם תיקיית יעד.
2. לחצו על מיין שירים או על תקן שמות ועיינו בתוכנית. שום קובץ לא משתנה לפני האישור.
3. אשרו את הביצוע.

לפני הביצוע סגרו תוכנות או סנכרון שעלולים לשנות את התיקיות עד לסיום.
אם תוכן התיקיות השתנה מאז הבדיקה, הביצוע נעצר.

תיקון שמות ותגיות
------------------
תגיות מתוקנות ב־MP3, FLAC, Ogg Vorbis, Opus, M4A ו־WavPack, בכל מבנה תגיות שהתוכנה יכולה לאמת.
לפני החלפת תגיות נשמר עותק מקורי לצד הקובץ, בכוונה. אפשר למחוק אותו אחרי שבדקתם את התוצאה.
קובץ שפורמט התגיות שלו אינו נתמך מדווח כתוצאה חלקית, גם אם שמו תוקן.

אם פעולה נקטעה
---------------
עצירה אינה מבטלת קבצים שכבר הועתקו או הועברו. התוצאות מציגות מה הושלם ומה דורש בדיקה.
בתפריט התוכנה אפשר לבדוק פעולות קודמות. הבדיקה אינה מפעילה שוב פעולות ואינה מוחקת קבצים.
אין למחוק יומן או גיבוי, או לחזור על פעולה שנקטעה, לפני שבדקתם את הקבצים.

רישוי ואימות
------------

ו־provenance.json מתאר את מקור הבנייה.

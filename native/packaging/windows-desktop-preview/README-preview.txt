מסדר הסינגלים: תצוגה מקדימה למחשב עם המודלים המקוריים
=====================================================

זו גרסת ניסוי ל־Windows x64. היא קוראת קבצים ומציגה תוכנית מיון בלבד.
אין בה ביצוע מיון, העתקה, העברה או שינוי תגיות של קובצי המוזיקה.
הגדרות אישיות ורשימת אמנים נשמרות רק בפעולות השמירה המפורשות בממשק.
זו אינה גרסת ההפצה המלאה ואינה חבילת Android.

דרישות
-------
Microsoft Edge WebView2 Evergreen Runtime ו־Microsoft Visual C++
Redistributable x64 מעודכן צריכים להיות מותקנים במחשב.
הוראות והורדות רשמיות:
https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution
https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170

החבילה אינה מתקינה או כוללת את סביבת WebView2 או את קובצי זמן הריצה
של Visual C++. רכיב הטעינה של SDK WebView2 מקושר לתוך ה־EXE;
הרישיון וההודעות שלו מצורפים ב־licenses.
אין צורך ב־Python, Rust, Node.js או בכלי פיתוח.
שני המודלים המקוריים פועלים מקומית בספריית Rust, בלי שירות AI ברשת
ובלי הורדת מודלים בזמן השימוש. הדבר אינו הבטחה לבידוד רשת של רכיבי
מערכת ההפעלה ו־WebView2. מחשב ללא הדרישות המוקדמות לא נבדק.

הפעלה
------
חלצו את כל ה־ZIP לתיקייה חדשה, גם אם שמה כולל רווחים או עברית.
פתחו singles-sorter-preview.exe. אין להעתיק רק את קובץ ה־EXE:
חמשת קובצי המודלים חייבים להישאר ב־models\original שלידו.
אם Windows מבקש הרשאה חריגה או מציג אזהרת אבטחה, אין לעקוף אותה.
זו חבילת בדיקה ללא מתקין וללא הבטחה לחתימה דיגיטלית.

לבדיקה ראשונה בחרו בתיקיית examples\source כמקור ובתיקיית
examples\target כיעד. אלו שני קובצי WAV שקטים שנוצרו לצורך הבדיקה.
בחרו בזיהוי המקורי והפעילו תצוגה מקדימה. בדוגמה ישראל כהן אמור להיות
מזוהה דרך המודלים; הדוגמה אברהם פריד יכולה להיפתר באמצעות רשימת האמנים.
אפשר לבחור גם זיהוי כבוי. אין חובה להפעיל AI כדי להשתמש בכללי הרשימה.

אפשר לבטל תצוגה פעילה או לחזור למסך הקודם, ואז להתחיל מחדש.
ביטול אינו אישור שהתוכנית הסתיימה בהצלחה; תוצאה ישנה לא צריכה להיות
מוצגת כתוצאה של בקשה חדשה. מודל חסר או פגום מונע זיהוי מקורי,
ללא החלפה במודל אחר וללא מעבר שקט לזיהוי כבוי.

בדיקת מקור ושלמות
-----------------
SHA256SUMS.txt כולל גיבוב לכל קובץ, מלבד עצמו. provenance.json
כולל מקור הבנייה, גיבובי המודלים, ספריות ה־PE והצלבת dumpbin.
licenses כולל הודעות, רישיונות וקוד מקור רלוונטי. TagLib מופץ כאן
במסלול MPL1.1; ראו licenses\SOURCE-AVAILABILITY.md לפרטי המקורות,
בחירות הבנייה והשינויים. אין כאן הבטחה גורפת לעמידה בכל דרישה משפטית.

בדיקות CI אמיתיות מפעילות את ממשק Windows בהרשאות משתמש רגיל,
כולל זיהוי מקורי, ביטול, חזרה, חזרה על הפעולה ומודלים פגומים.
הבדיקות משוות את תוכן המקור, היעד והמודלים, שמות, הרשאות וזמני שינוי.
זמן הגישה עשוי להתעדכן בעת קריאה ואינו חלק מהבטחת השימור.
